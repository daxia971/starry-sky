# 满天星 · 变色星空 Starry Sky

一个零依赖的单文件星空网页：满天星闪烁漂移、随机流星，底部色板可切换 7 种颜色主题（含彩虹模式），还有三个会互动的卡通小伙伴。

**在线预览**: https://daxia971.github.io/starry-sky/

## 玩法

- 点击底部圆点切换星空颜色主题（银白 / 冰蓝 / 樱花粉 / 鎏金 / 翡翠绿 / 暗夜紫 / 彩虹）
- 点击夜空任意处许愿一颗流星
- 点宇航员：翻跟头并连放 3 颗流星
- 点月牙上的小猫：随机喵语气泡
- 点小星星精灵：旋转放流星，它的颜色会跟随当前主题

## 技术

纯 HTML + Canvas + 内联 SVG（SMIL/CSS 动画），无任何外部依赖，下载 `index.html` 双击即可运行。
